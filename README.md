# PA-Marine demo site

Static GitHub Pages site for **PA-Marine-Model**, a research-prototype weekly forecast of *Dinophysis* (DSP shellfish toxin) blooms in Irish waters, by **Garry Lohan (ATU Galway)**. Ocean Hackathon Cork 2026 demo.

- `/` — landing page
- `/map/` — interactive map demo
- `/wiki/` — project wiki (static HTML/CSS/JS, hash router, no build step)

No model code, raw data or station-level results live here: national, regional and yearly aggregates and method descriptions only.
Not an official Marine Institute product or advice.
