# PA-Marine demo site

Static GitHub Pages site for **PA-Marine-Model**, a research-prototype weekly forecast of *Dinophysis* (DSP shellfish toxin) blooms in Irish waters, by **Garry Lohan and Felix Sproll**.

- `/` — landing page
- `/map/` — interactive map demo
- `/wiki/` — project wiki (static HTML/CSS/JS, hash router, no build step)
- `/tour/` — guided tour: step-through presentation (← → / swipe, `N` speaker notes with timer and a synced presenter window, `O` step overview, `F` full screen, `#n` deep links)

This demo publishes per-station weekly history, the current risk band and the full test log, all derived from public Marine Institute data. No model code, training pipeline or frozen model lives in this repo.
Not an official product or official advice.
